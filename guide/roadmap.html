RoadMap ​

XnneHangLab 项目的开发路线图与技术债务清理计划。（更新于 2026-07-08）

记忆系统：LLM Mode ​

状态： 设计完成（ADR-0001），实施中 优先级： 高 设计文档： ADR-0001 | ADR-0002 | #471 / #468

用 categories + wiki-links + metadata 的扁平存储取代 Neo4j 语义节点（Domain / Topic / Scene / Predicate），结构节点（Agent / Character / User / Conversation）保留用于可视化。设计借鉴 memU（不引入其依赖，见 ADR-0002）。

里程碑：

里程碑内容Issue状态
M1存储层 — categories + metadata + 扁平条目#478待开工
M2检索 — wiki-link [[category:item]] 解析与关联抓取#479待开工
M3MemoryPlugin 接入 — 默认 LLM Mode，embedding 可选融合，mem0 迁移回退#480待开工
M4Neo4j 语义节点退役 — 实时管线停产语义节点#481待开工

后续方向：

  • Multi-Character 记忆（#470 / #469）— Agent 画像独立为 LLM Mode + User 模板继承
  • mem0 / Neo4j 基准线 — 退回 memory_bench 基准对照定位；embedding + graph traversal 作为研究线按基准数据立项（远期，非运行时并行模式）

TTS 统一调度 ​

状态： 规划中 优先级： 中 关联： #402

统一 TTS 引擎（Genie-TTS / GSV-TTS-Lite / Qwen-TTS）的调度层，集中管理语音资源与情绪配置。

插件与感知 ​

  • AudioTriggerPlugin（#368）— 预制音频库 + 大模型触发 + Live2D 联动
  • 异步 Screen Observation / Vision Input 插件架构（#380）— 初版已由 visual_observer 插件落地（OCR 轮询 + 场景切换检测 + vision boost），作为 agent core 额外输入的通用架构化仍在设计
  • 统一 vision pipeline（#353）— 将更多 tool callback image 接入统一视觉管线

独立翻译大模型 ​

状态： 规划中 优先级： 中

当前翻译依赖外部 DeepLX 服务与本地 GGUF 小模型（/translate/llm），计划评估更强的独立翻译模型。

候选模型：

  • Tencent-Hunyuan/HY-MT1.5-1.8B — 腾讯混元翻译模型

待完成：

  • [ ] 模型集成与推理封装
  • [ ] 路由层适配（保持 API 兼容）
  • [ ] 性能对比测试（vs DeepLX / Qwen2.5-0.5B）
